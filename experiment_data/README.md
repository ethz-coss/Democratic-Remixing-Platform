# Raw Data Bundle — Remix Platform Thesis

Self-contained archive of all raw data needed to reproduce every derived result
in the thesis (simulation figures, study analysis, evaluation metrics).

**Extracted on:** 2026-09-07 (human studies), 2026-08–09 (simulation experiments)

## Contents

### `human_studies/`

`tooling/evaluation/extract/export.py`. Each cohort directory contains the full
set of database collections for that study group.

### `simulation_experiments/`

JSON run reports for computational experiments S1–S12, covering:
- One-at-a-time parameter sensitivity (S1)
- Ballot configuration ablation (S2)
- Dual-window/PersonalFocus ablation (S3, S4)
- Population scaling (S5, S10, S11, S12)
- Quality-aware voting (S6–S9)

Each JSON contains the full decision log, evaluation snapshot (proposals,
votes, subscription counts, DAG structure), quality registry, and time events.

**123 JSON files**, 3 random seeds (42, 99, 137) per configuration.

`experiment_results.csv` — Pre-computed aggregate metrics across all 123 runs,
generated by `tooling/simulations/experiments/collector.py`.

## How to regenerate derived outputs

```bash
# 1. Regenerate experiment_results.csv from the bundled JSONs
python -m tooling.simulations.experiments.collector

# 2. Regenerate all simulation figures (72 PDF + PNG)
python -m tooling.simulations.experiments.analysis

# 3. Run evaluation pipeline on a human study export
python -m tooling.evaluation.run_evaluation \
  --csv-dir experiment_data/human_studies/wg_netz_winterthur \
  --question-id <QUESTION_ID> \
  --compute-metrics

# 4. Run the Jupyter analysis notebooks
jupyter notebook tooling/evaluation/notebooks/wg_netz_study_analysis.ipynb
```

## Privacy

All user identifiers in the CSV exports are pseudonymised (MD5-hashed to 16-char
hex strings). Names, avatars, and usernames are wiped. Email addresses are
replaced with `<pseudo_id>@pseudo.local`. No real PII is stored in this bundle.
